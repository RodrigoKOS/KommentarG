# KommentarG

API estilo Elfsight para buscar comentários/avaliações do Google Meu Negócio (Google Business Profile) e exibir em sites para gerar mais credibilidade.

## Objetivo
- Conectar contas/locais do Google Business Profile
- Buscar e armazenar reviews
- Expor via API + widget embeddável (JS) para sites de clientes
